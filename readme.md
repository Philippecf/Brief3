## Todo list

Petite application web en JavaScript qui permet d'ajouter des éléments à une liste en les saisissant dans un champ de texte.

## Fonctionnement

Le fichier script.js :

1. Récupère dans la page les éléments input, button et ul avec document.querySelector.
2. Écoute le clic sur le bouton avec addEventListener.
3. À chaque clic, crée un nouvel élément li avec document.createElement, y place la valeur du champ de texte, puis l'ajoute à la liste avec appendChild.

## Technologies utilisées:

- HTML5
- JavaScript
